# kicad/tools/layout: layout, routing, silkscreen and fab scripts

Run the pcbnew ones with KiCad's own Python (`%LOCALAPPDATA%\Programs\KiCad\10.0\bin\python.exe`); `export_fab.py` and
`set_pcbway_rules.py` run with the normal `py`. Always close the PCB editor first, back the board up, and never run a
script that writes a board over hand-edited work you have not checked. See `../../README.md` for the workflow and gotchas.

| Script | Reusable? | What it does |
|---|---|---|
| `export_fab.py` | **yes, any board** | kicad-cli Gerbers (7 layers) + Excellon drill (PTH/NPTH split) + drill maps, zips the upload files. Refuses if the PCB editor has the board open. Reproduced the gauge board's PCBWay files exactly (apart from date headers). |
| `tidy_silk.py` | **yes, any board** | Re-places only reference-designator text (size and angle set, avoids pads, silk outlines, holes, board edge, each other, stays next to its part). `python.exe tidy_silk.py in out [size_mm]`. Footprint positions are never changed. |
| `remove_pads.py` | yes | Remove pads (optionally only non-plated) from named footprints on a board. Used to drop the ADS122C04 module mounting holes. |
| `check_pad_nets.py` | **yes, any board** | Read-only: for every part, compares the netlist's pin numbers with the footprint's pad numbers and lists parts that would get no nets. Run after building a board from a netlist. |
| `set_pcbway_rules.py` | yes | Writes the PCBWay 2-layer rules (6/6 mil, 0.3 mm drill, edge clearance, default net class) into a `.kicad_pro`. |
| `gauge_initial_placement.py` | template | First-draft board creation from a netlist (footprint loading, schematic UUID path, nets, `place_pair` helper, outline, M3 holes). Its placement was superseded by the owner's hand layout. |
| `main_initial_placement.py` | historical | First-draft main-board creation and placement from `hastadaq.net` (coordinate table `PLACE`, outline, M3 holes). Refuses to overwrite an existing `.kicad_pcb` without `--force`. The owner's hand-tweaked board (62.1 x 89.4 mm) is the source now; do not re-run it. |
| `grid_router.py` | **yes, any 2-layer board** | Small octilinear A* router (pure Python + numpy, no pcbnew): 0.1 mm grid, per-track-width clearance maps, through-hole and SMD pads, vias with a hole-to-hole mask, hard keep-outs, tree-per-net, no rip-up. Run with KiCad's python (it has numpy). KiCad DRC is the real judge of its output. |
| `route_main.py` | board-specific | Main-board routing on a PLACED board: `python.exe route_main.py placed.kicad_pcb routed.kicad_pcb`. Removes all tracks/zones first. Hand-routed 2.0 mm VSERVO (F.Cu) and +12V (B.Cu) bars, router for the rest (+5V/+5V_VSYS 0.8, +3V3 0.5, signals 0.25), GND pours on both layers, 6 mm stitching vias, rule-area keep-outs. The User.Comments rectangles (SP/CE connector, plug clearance) only keep COMPONENTS out, so copper may cross them (`ROUTE_KEEP_TOP=1` makes them top-layer copper keep-outs again). Honours the Pico footprint's own "Antenna Copper Keep Out" (both layers; harmless on the Plus 2, needed if a Pico W is fitted). No rip-up, so it **restarts itself** (up to 8 attempts) with failed nets routed first, then gives GND pads that ended on pour islands a stub+via and, if that fails, a real track to the nearest connected GND pad. Env: `ROUTE_DEBUG=1` prints a blocked-cell map around a failed pad; `ROUTE_GNDBUS="U1.18+U1.23,U1.13+R11.2+D3.2+U1.28"` routes those GND pads together with 0.5 mm tracks before the signals (this is what cleaned up the GND around the hidden R11/D3; without it the stub/tie fallback made 8 long GND ties). Run `trim_fp_keepout.py` first, then `route_main.py`, then `solid_gnd_pads.py` on a fresh DRC report. |
| `trim_fp_keepout.py` | yes | `python.exe trim_fp_keepout.py in out REF MM`: cuts MM off the top edge of a footprint's own keep-out rule area on this board only (used for the Pico's antenna area, 3 mm, so the mid-row GND pins can be bridged). Library unchanged, so DRC shows `lib_footprint_mismatch`. |
| `solid_gnd_pads.py` | **yes, any board** | Reads a DRC report and sets every pad listed as `starved_thermal` to a solid zone connection, then re-fills. `python.exe solid_gnd_pads.py board drc.rpt [out]`. |
| `gauge_route_as_built.py` | record | The exact routing applied to the gauge board. Coordinates are hard-coded; not general. Encodes the conventions (layers, widths, pours, keepouts, stitching) worth reusing. |
| `gauge_check_lengths.py` | record | Read-only path lengths for ADS_REF legs, SIG runs, A0/A1 links on the gauge board. |
